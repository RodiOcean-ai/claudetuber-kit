# Ad story engine

Every ad is a tiny story. Five elements, in a causal chain. Use these definitions, not textbook ones.

1. **Goal** — the one thing the hero fights for; it never changes. Every beat must move toward it. *Removal test:* if a beat can be cut and the chain still holds, cut it.
2. **Obstacle** — a circumstance that *threatens* the goal (not just costs something). Name what is at risk and whether it is local (one beat) or global (the whole goal).
3. **Tactic** — the move the obstacle forces: a reasonable guess on what the character knows. A failed tactic must teach something; a tactic with no reason is a wheel-spin.
4. **Reversal** — a turn against expectation: (a) the hero's own action flips on him, (b) hidden agency is revealed (someone else was steering), or (c) the situation turns opposite to the tactic. **At least one per ad.**
5. **Value shift** — the change in the *audience's* verdict about a character, caused by the reversal ("lazy boyfriend → he's been scared, not lazy → she planned all of it"). **A reversal with no value shift is inert — the #1 thing to fix.**

## Ad-specific rules
- **The product must cause the reversal** or be the tool of the tactic; a product that only appears at the end is decoration.
- **Rule of three:** set-up, set-up, punch. Repeat a line or sound exactly (same words, same delivery) so the third one can turn.
- **Never foreshadow the twist in words.** Plant it visually (an object in plain sight) so a rewatch rewards; jokes about the twist go *after* it.
- **The jingle is a story device,** not a bed: it should carry the tactic (the "cure" working) and, ideally, walk the viewer to the reversal (e.g. it cuts off on the line it won't sing).
- **One location per beat, one action per shot,** because AI video breaks when a beat asks for two things.
- **Length budget:** 15 s = 1 reversal; 30 s = set-up ×3 + product + reversal; 45 s = add one escalation. Contest limits win over the story.
- **Taste guard:** no ending that relies on sexual innuendo, real brands, children's voices or gore.

- **Define the product's power exactly (SKIP)** and keep it consistent: SKIP jumps forward in time and never teleports. Show it the same way every time, so the first use teaches the picture language and the third use can turn it.
- **Plant the reversal's agent visually (SKIP):** the man who skips the hero at the end stands in the first scene's wreckage, staring at him. No words. A rewatch rewards it.
- **The tail can turn on the viewer (SKIP):** "Everyone gets one" ended with the presenter skipping the viewer reaching for "Skip Ad". The tagline becomes the punchline.

## Modes
- **AUDIT:** run the chain in order and report in the template below.
- **WRITE:** name all five elements *before* writing; when giving options, they must differ in tactic or reversal, not just tone.

## Audit template
```
AD: <one line>
CHAIN
• Goal — <verdict + line>
• Obstacle — <what's at risk, local/global, verdict>
• Tactic — <forced? reasonable? teaches something? verdict>
• Reversal — <form a/b/c, present?, verdict>
• Value shift — <before-verdict → after-verdict, or "INERT">
WEAKEST POINT: <the one element that, fixed, recovers the most>
FIXES: 1) minimal (keep the user's version) 2) clean (fully works) 3) optional
BEAT SHEET: <time range | picture | sound | element it serves>
```

## Failure fixes
| Symptom | Fix |
|---|---|
| Twist doesn't surprise | something earlier told us; move that hint after the twist, keep only a visual plant |
| Twist surprises but nobody cares | inert reversal: name the before/after verdict and rewrite until it changes |
| "Why would he do that?" | missing motive: give the product a giver (who hands it over and why) |
| Ad feels like a list | beats aren't causal: each beat must create the next |
| Too long | cut the beat that fails the removal test, never the reversal |
