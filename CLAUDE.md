# This folder: the free Claude Code video kit from the RodiOcean channel

- When the person is new, asks where to begin or types **/start-claudetube**, use the `start-claudetube` skill (the guided start).
- When the person types **install** (or "set it up", "install the kit"), follow `INSTALL.md` step by step.
- `short-factory/` is a Claude Code plugin (skills, agents, commands); `eleven-styles-sandwich/` is a Remotion project.
- Talk in plain English, ask before installing or downloading anything, never spend money or press Generate in a paid
  tool, and never enter passwords: the person signs in to their own accounts.
