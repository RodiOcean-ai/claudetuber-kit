# Sound effects (bring your own)

The styles call these files by name (all short WAVs): blip, boom, bump, bump2, card, card2, circle, click, confirm, crack,
ding, fizz, gulp, jump, mclick, page, paper, pop, pop2, riser, smack, sparkle, stroke, swipe1, swipe2, swipe3, swish1,
swish2, thud, tick, uiclick, whip, whoosh, yippee, zip1, zip2 (`.wav`). The author's files are not included (paid or
licence-limited). Free sources: Openverse or Freesound (CC0 preferred). `tools/sfx.py` trims and levels a sound for you.
